# Telegram Game Creator Bot

Новый бот: пользователь отправляет описание игры, бот генерирует HTML-игру и отправляет результат.

- Без GitHub: бот отправляет `index.html` файлом в Telegram и сохраняет локально.
- С GitHub (опционально): дополнительно публикует файл в репозиторий и даёт публичные ссылки.

## Что делает бот

- принимает текстовое описание игры от пользователя;
- создаёт HTML-файл с простой игрой (canvas + JavaScript);
- без GitHub: отправляет HTML-файл игры в чат;
- с GitHub: пушит `index.html` в репозиторий через API и возвращает ссылки на запуск/код.
- с AI API: генерирует более качественные и разнообразные 3D-игры по вашему описанию.

---

## 1) Подготовка

1. Создайте Telegram-бота через **@BotFather** и получите токен.
2. (Опционально) Создайте GitHub токен (PAT) с правами записи в репозиторий.
3. (Опционально) Убедитесь, что у вас есть репозиторий, куда бот будет сохранять игры.

---

## 2) Настройка

В папке `telegram_game_creator_bot`:

1. Скопируйте `.env.example` в `.env`.
2. Обязательно заполните:

- `TELEGRAM_BOT_TOKEN`

3. Опционально заполните GitHub-переменные (если хотите публичные ссылки):

- `GITHUB_TOKEN`
- `GITHUB_OWNER`
- `GITHUB_REPO`
- `GITHUB_BRANCH`

4. `GAMES_BASE_PATH` можно оставить по умолчанию.

5. Для максимального качества заполните AI-переменные:

- `AI_API_KEY`
- `AI_BASE_URL` (по умолчанию `https://api.openai.com/v1`)
- `AI_MODEL` (например `gpt-4.1-mini`)
- `AI_TIMEOUT_SECONDS`

Если хотите красивую ссылку через GitHub Pages, задайте `GAME_LINK_BASE`.

---

## 3) Установка

```bash
pip install -r telegram_game_creator_bot/requirements.txt
```

---

## 4) Запуск

```bash
python telegram_game_creator_bot/main.py
```

---

## 5) Использование

1. Откройте диалог с ботом.
2. Нажмите `/start`.
3. Отправьте сообщение с описанием игры, например:

`Космическая игра, где корабль уворачивается от астероидов`

4. Бот пришлёт результат:
   - без GitHub: файл `index.html`;
   - с GitHub: ссылку на игру и ссылку на код.

При включённом `AI_API_KEY` бот сначала пытается сделать уникальную 3D-игру через API.
Если API недоступен — использует встроенный 3D-шаблон.

---

## Важно про ошибку 409 Conflict

Если в логах видите `terminated by other getUpdates request`, значит запущено несколько копий бота с одним токеном.
Оставьте только один процесс `python telegram_game_creator_bot/main.py`.

---

## Примечания

- Сейчас генерация делает простой шаблон 2D-игры на JS.
- Каждая игра сохраняется в отдельную папку по пути `GAMES_BASE_PATH/<id>-<slug>/index.html`.
- Для продакшн-сценария можно добавить очередь задач, БД и более сложную генерацию через LLM/API.
