# Frendy Assistant — Android

Мобильное приложение-голосовой помощник.

## Что реализовано

- Активация фразой: **«привет фрэнди»**
- Ответ помощника: **«Привет, что хотел?»**
- Затем слушает вопрос и отвечает голосом
- Разрешение на микрофон запрашивается при запуске

## Точность ответов

Для точных ответов используется OpenAI API.

### Как добавить ключ

1. Открой `android_webview_app/gradle.properties`
2. Добавь строки:

```properties
OPENAI_API_KEY=sk-xxxx
OPENAI_MODEL=gpt-4o-mini
```

Если ключ не задан, приложение покажет сообщение, что ключ отсутствует.

## Сборка APK/AAB

1. Установи Android Studio (JDK 17 + Android SDK 34)
2. Открой папку `android_webview_app`
3. Дождись Gradle Sync
4. Запусти на телефоне кнопкой **Run**

CLI (из `android_webview_app`):

```bash
gradlew.bat assembleDebug
```

APK будет в:

`app/build/outputs/apk/debug/app-debug.apk`

## Важно про заблокированный экран

На Android постоянное «слушание» на заблокированном экране ограничено системой и режимами энергосбережения.
Стабильнее всего помощник работает, когда приложение открыто на телефоне на переднем плане.
