# Telegram Proxy Sales Bot

Бот продаёт прокси по тарифам и отправляет оплату на ваш номер **9026303200**.

## Логика

1. Пользователь нажимает `/start`
2. Видит тарифы:
   - `30 ДНЕЙ-1000РУБ`
   - `ГОД-5000РУБ`
   - `5ЛЕТ-10000РУБ`
3. Выбирает тариф, получает реквизиты оплаты на `9026303200`
4. Нажимает **«Я оплатил»**
5. Бот автоматически проверяет, есть ли платёж с нужной суммой и комментарием заявки
6. Если платежа нет — бот пишет: **«Вы не сделали оплату. Прокси не выдано»**
7. Если платеж найден — бот пишет: **«Оплата найдена. Прокси выдано»** и выдаёт доступ

> Выдача полностью зависит от файла `proxy_pool.json` (там должны быть реальные рабочие прокси).
> Проверка оплаты зависит от входящих платежей в `state.json -> payments`.

## Файлы

- `main.py` — код бота
- `.env` — конфигурация
- `state.json` — заявки и активные подписки (создаётся автоматически)
- `proxy_pool.json` — пул реальных прокси (создайте из примера)
- `proxy_pool.example.json` — пример формата

## Настройка

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Заполнить `.env`:

```env
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН
OWNER_TELEGRAM_ID=9026303200
PAYMENT_PHONE=9026303200
PAYMENT_NOTE=Оплата прокси
```

3. Создать пул прокси:

```bash
copy proxy_pool.example.json proxy_pool.json
```

4. В `proxy_pool.json` вписать **реальные рабочие** прокси:

```json
[
  {
    "host": "REAL_IP",
    "port": 1080,
    "username": "user1",
    "password": "pass1",
    "protocol": "socks5"
  }
]
```

5. Запуск:

```bash
python main.py
```

## Команды

- `/start` — тарифы и покупка
- `/status` — показать текущий активный прокси и срок
- `/myid` — показать ваш Telegram ID
- `/income <сумма> <комментарий> [телефон]` — добавить входящий платеж (команда только для владельца)

### Пример автопроверки

1. Пользователь выбрал тариф и получил комментарий, например: `Оплата прокси #a1b2c3d4e5`
2. Владелец добавляет поступивший платеж:

```bash
/income 1000 Оплата_прокси_#a1b2c3d4e5 79001234567
```

3. После этого при нажатии пользователем **«Я оплатил»** бот сам сверяет платеж:
   - если есть совпадение по сумме + `#req_id` → выдаёт прокси;
   - если нет совпадения → отказывает в выдаче.

## Важно

- Чтобы прокси «реально работало», нужно добавить в `proxy_pool.json` живые прокси-серверы.
- Бот не поднимает прокси-сервер сам, он только выдаёт доступ из вашего пула.
